## ЧАСТЬ 3 — Если что-то не работает

### «Не открывается http://192.168.100.123:7766»

1. Проверь Wi-Fi — ты на той же сети что Юджин?
2. Юджин — запущен ли Очаг? Команда: `C:\Projects\Ochag\ochag.exe`. Должен показать «Listening on :7766».
3. Firewall на Юджининой машине — может блокировать. Юджин разрешит порт 7766.

### «Команда python не найдена»

Установи Python с python.org (Алёна) или используй WinPython.

### «Лара-PawMate не может подключиться даже с правильным IP»

Возможно `ochag.py` не поддерживает remote host. Эфир (я) тогда патчу client — попроси через Алёну в чате.
